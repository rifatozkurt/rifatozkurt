## Hi, I'm Rıfat 👋

I work on machine learning, mostly computer vision, LLMs and scientific ML, and spend the rest of my time designing and hacking the hardware it runs on.

At TUM, I've worked at the [Chair of Security in Information Technology](https://www.ce.cit.tum.de/en/eisec/mitarbeiter/georg-sigl/) with Prof. Georg Sigl and the [Chair of Machine Learning](https://www.professoren.tum.de/heckel-reinhard) with Prof. Reinhard Heckel, and wrote my M.Sc. thesis in Prof. Felix Dietrich's [Physics-Enhanced Machine Learning group](https://www.cs.cit.tum.de/sccs/personen/felix-dietrich/).
